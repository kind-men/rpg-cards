Create, customize, organize, and print RPG cards from your browser.

RPG Card Generator is a friendly workspace for making cards for tabletop games: spells, items, abilities, conditions, campaign handouts, quick-reference cards, or anything else that deserves to live on a neat little card. Build a deck, tune the layout, add icons and card backs, preview the result, then print or export it when it is ready for the table.

Use it here: <https://kind-men.github.io/rpg-cards/>

## What You Can Do

- Create decks of custom RPG cards.
- Edit card text, colors, icons, layout, and card backs.
- Import and export deck data as JSON.
- Print cards with configurable paper, margins, card sizes, and backs.
- Use built-in documentation when you need the exact card data format or workflow details.

## Documentation

Documentation can be found at <https://kind-men.github.io/rpg-cards/docs/>.

## Local Development

This is a SvelteKit project. To run it locally:

```sh
pnpm install
pnpm dev
```

Useful commands:

```sh
pnpm check
pnpm test
pnpm build
```

## Project Lineage

This project was inspired by and originally forked from [Mathias Andresen's RPG Cards](https://github.com/mathiasandresen/rpg-cards). It has since grown into its own version, with its own hosted app, documentation, features, and direction.

Thanks to Mathias Andresen, [mephitrpg/rpg-cards](https://github.com/mephitrpg/rpg-cards), and the original [crobi/rpg-cards](https://github.com/crobi/rpg-cards) project for laying the groundwork.
